## Supported Versions

Security fixes are considered for the latest released version of DayCalcy.

| Version | Supported |
|---|---|
| 3.42.9 | Yes |
| Older versions | No |

## Reporting a Security Issue

If you discover a security or privacy issue in DayCalcy, please report it privately through GitHub rather than publicly posting details.

DayCalcy is designed to work completely offline and does not require network access, online accounts, or remote services.

Please include:
- DayCalcy version
- Android version
- Device model
- Steps to reproduce the issue
- Any relevant screenshots or logs

Thank you for helping improve DayCalcy.
